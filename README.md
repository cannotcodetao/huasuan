# 划算

消费决策计算器 — 用数字帮你看清每一笔消费。

## 它能做什么

把大额消费换算成你熟悉的日常单位，让抽象的价格变得可感知。

- **购车 vs 打车**：养车成本折算成每年能打多少公里，附绕地球/纵穿中国类比
- **购房 vs 租房**：房价折算成能租多少年，看清盈亏平衡点
- **做饭 vs 外食**：毛利率反推外食真实成本，算清一年省多少

## 技术

纯静态页面，HTML + CSS + JavaScript，无框架无依赖，打开即用。

## 本地运行

```bash
git clone https://github.com/cannotcodetao/huasuan.git
cd huasuan
python -m http.server 8080
```

打开 http://localhost:8080/calculator.html
