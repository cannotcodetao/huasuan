# 划算

个人财产健康守护工具 — 用数字看清你的钱，而不是替你管钱。

## 定位

大多数理财应用让你记账、连账户，最后变成负担。划算反其道而行：不做记账簿，只做**看清**——

1. **看清这笔消费**：大额消费换算成日常单位，价格变得可感知
2. **看清每月现金流**：收入、支出、结余、贷款月供与利息，一目了然
3. **看清未来计划**：每笔储蓄计划推演到多年后值多少；距离退休的资金缺口

目标用户：不想记账、但想对钱有概念的人。

## 页面

| 页面 | 一句话 |
|------|--------|
| [首页](index.html) | 现金流（收入/支出/贷款）+ 未来计划独立预测 + 总资产/退休测算 |
| [消费决策](calculator.html) | 购车 vs 打车、购房 vs 租房——价格换算成可感知单位 |

贷款支持等额本息 / 等额本金两种算法，可记录每月还款日。

## 数据隐私

所有数据保存在浏览器 localStorage，**不上传任何服务器**。支持导出 / 导入 JSON 备份。

在支持 File System Access API 的浏览器（Chrome / Edge）里，还可以把一个本地 JSON 文件绑为数据文件，
之后每次改动自动同步写入。绑定以该文件为准：文件里有数据就加载进页面，文件是空的就把当前数据写进去，
文件内容不是划算备份则直接拒绝、两边都不动。绑定时可选择先另存一份当前数据。

## 技术

纯静态页面，HTML + CSS + 原生 JavaScript，无框架无构建工具。

## 本地运行

```bash
python -m http.server 8080
```

打开 http://localhost:8080/
